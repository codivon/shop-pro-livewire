## معرفی

شاپ‌پرو یک سیستم فروشگاه‌ساز کامل برای بازار ایران است: فروش چندفروشندگی، محصولات با تنوع و
پیش‌فروش، سبد خرید و چک‌اوت یک‌مرحله‌ای، درگاه‌های پرداخت شتابی و کیف پول، باشگاه مشتریان و
امکانات بازاریابی. پنل مدیریت با **Livewire** ساخته شده و هیچ وابستگی به فریم‌ورک‌های SPA ندارد؛
همه‌چیز داخل هسته است و امکانات تخصصی در قالب «پکیج» از بازارچهٔ داخلی نصب می‌شوند.

زبان رابط کاربری و دیتابیس فارسی/RTL است و تقویم جلالی در سراسر سیستم استفاده می‌شود.

## ویژگی‌های کلیدی

| حوزه | امکانات |
| --- | --- |
| فروشگاه | محصولات چندتنوعی، پیش‌فروش تنوع‌محور، هشدار کاهش قیمت، نظرات، علاقه‌مندی‌ها، جست‌وجوی یکپارچه |
| چک‌اوت | درگاه‌های شتابی (زرین‌پال، سپ/سامان، دیجی‌پی، اسنپ‌پی، آیدی‌پی و…)، کیف پول، پرداخت قسطی، بازگشت وجه |
| چندفروشندگی | پنل مستقل فروشنده، ثبت‌نام مرحله‌ای با احراز هویت شاهکار، کمیسیون و تسویه، محدودیت برند و مالکیت محصول |
| پنل مدیریت | Livewire واکنش‌گرا، مانیتور سیستم و لاگ کندی‌ها (Pulse)، مدیریت نشست‌ها، رول‌بک آپدیت |
| بازارچه پکیج‌ها | نصب/به‌روزرسانی خودکار با مانیفست امضاشده، لایسنس و اشتراک، گیت شخصی‌سازی برای هر امکان |
| امنیت | کپچاهای چندگانه (تصویری، ریاضی، hCaptcha، Cloudflare Turnstile)، ورود دومرحله‌ای مدیر، تلهٔ ربات، OTP |
| محتوا | مقالات، برگه‌ها، فرم‌ساز، بنر و ابزارهای صفحهٔ اصلی، قالب‌پذیری تم (Saniar) |
| زیرساخت | سایت‌مپ خودکار، API نسخهٔ ۱، وب‌پوش، پیامک (کاوه‌نگار/ملی‌پیامک)، لاگ چرخشی، کیت مقیاس‌پذیری |

## معماری و تکنولوژی‌ها

| لایه | فناوری |
| --- | --- |
| بک‌اند | Laravel 13 (PHP 8.3+) |
| فرانت پنل | Livewire 4 + Alpine.js + استایل اختصاصی |
| دیتابیس | MySQL / MariaDB (10.11+)، Redis برای کش و صف (اختیاری) |
| دارایی‌ها | Vite + Webpack Mix (قالب)، Tailwind CSS |
| بسته‌ها | Spatie Sitemap، Laravel Pulse، Intervention Image، maatwebsite Excel، morilog/jalali |
| پکیج‌های همراه | `packages/shetabit/multipay` (درگاه‌ها)، `packages/codedge/laravel-selfupdater` (به‌روزرسانی خودکار) |

## پیش‌نیازها

- PHP 8.3 یا بالاتر با افزونه‌های `mbstring, xml, ctype, curl, dom, fileinfo, gd, iconv, intl, zip, bcmath, pdo_mysql`
- Composer 2
- MariaDB 10.11+ یا MySQL 8+
- Node.js 20+ (برای بیلد دارایی‌ها)
- Redis (اختیاری — برای کش و صف در ترافیک بالا)

## نصب

```bash
# ۱) دریافت کد
git clone https://github.com/codivon/shop-pro-livewire.git shoppro
cd shoppro

# ۲) وابستگی‌ها
composer install

# ۳) پیکربندی محیط
cp .env.example .env
php artisan key:generate
# مقادیر دیتابیس (DB_DATABASE و ...) را در .env تنظیم کنید

# ۴) بیلد دارایی‌ها
npm install && npm run build
```

سپس برنامه را اجرا کنید و نخستین بازدید، **نصب‌کنندهٔ وب** را باز می‌کند:

```
php artisan serve        # یا vhost خود را به پوشهٔ public اشاره دهید
# مرورگر: https://example.com
```

نصب‌کننده به‌صورت مرحله‌به‌مرحله مایگریشن، سیدر و ثبت نخستین مدیر را انجام می‌دهد
(با نمایش پیشرفت زنده و قابلیت ادامه پس از قطعی).

<details>
<summary><b>نصب خط فرمانی (اختیاری)</b></summary>

```bash
php artisan migrate --seed
php artisan storage:link
touch storage/installed        # رد شدن از نصب‌کنندهٔ وب
```
</details>

<summary><b>اجرا در حالت توسعه</b></summary>

```bash
php artisan serve              # وب‌سرور محلی
php artisan queue:listen       # صف (اگر QUEUE_CONNECTION=sync نیست)
npm run dev                    # بیلد دارایی‌ها با HMR
```
</details>

## پیکربندی

| کلید | توضیح |
| --- | --- |
| `ADMIN_ROUTE_PREFIX` | پیشوند آدرس پنل مدیریت (پیش‌فرض `admin`) |
| `DB_CONNECTION` | `mysql` (پیش‌فرض) |
| `CACHE_DRIVER` | `file` — برای ترافیک بالا `redis` |
| `QUEUE_CONNECTION` | `sync` — در پروداکشن `redis` یا `database` |
| `MAIL_*` / `SMS_*` | تنظیمات ایمیل و پیامک |
| `PACKAGES_LICENSE_PUBLIC_KEY` | کلید عمومی راستی‌آزمایی لایسنس پکیج‌ها |

پنل مدیریت در آدرس `/admin` قرار دارد و حساب مدیر در پایان نصب ثبت می‌شود —
**بلافاصله پس از نصب، رمز آن را تغییر دهید.**

### کپچاهای چندگانه

برای هر نقطهٔ حساس سیستم می‌توانید به‌طور مستقل یک درایور کپچا انتخاب کنید
(پنل مدیریت ← تنظیمات برنامه‌نویس ← تب امنیت):

| نقطه | توضیح |
| --- | --- |
| `admin_login` | ورود مدیر |
| `register` | ثبت‌نام مشتری |
| `customer_login` | ورود مشتری |
| `seller_login` | ورود فروشنده |
| `comments` | ارسال دیدگاه |

درایورهای پشتیبانی‌شده: `image` (پیش‌فرض)، `math` (ریاضی با سطح پیچیدگی قابل تنظیم)،
`hcaptcha`، `turnstile`. کلیدهای ابری در همان تب ثبت می‌شوند و در دیتابیس ذخیره می‌گردند.

### سایت‌مپ

```bash
php artisan sitemap:generate          # تولید دستی
```

مسیرهای عمومی: `/sitemap.xml` (ایندکس) و `/sitemap/{type}-{n}.xml` برای مقالات،
صفحات ثابت و فروشگاه‌ها. تولید fail-safe است؛ خطای یک بخش، کل سایت‌مپ را نمی‌شکند.
کش ۲۴ ساعته دارد و پاک‌سازی آن از پنل مدیریت امکان‌پذیر است.

## API نسخهٔ ۱

اندپوینت‌های عمومی تحت `/api/v1` شامل محصولات، جست‌وجو، فیلترها، چک‌اوت و تأیید پرداخت
بدون نشست. مستندات کامل: [`docs/API-DOCUMENTATION.md`](docs/API-DOCUMENTATION.md)

احراز هویت با Sanctum انجام می‌شود.

## ساختار پوشه‌ها

```
app/
├── Console/Commands/        # دستورهای artisan (نصب دمو، سایت‌مپ، سلامت زیرساخت)
├── Http/Controllers/        # کنترلرها (Back، Seller، Api/V1)
├── Livewire/                # کامپوننت‌های پنل مدیریت و مشتری
├── Services/                # سرویس‌های هسته (کپچا، لایسنس، نصب پکیج، پرداخت)
└── Support/                 # تنظیمات ماژولار و هلپرها
packages/                    # پکیج‌های همراه (درگاه پرداخت، آپدیت خودکار)
resources/views/             # ویوها (پنل Livewire، فروشنده، نصب‌کننده)
themes/WeblakShop/           # تم فروشگاه (فروشگاه مشتری)
routes/                      # وب، پنل مدیریت، فروشنده، API
tests/                       # مجموعهٔ تست PHPUnit/CI
docs/                        # مستندات API و مقیاس‌پذیری
```

## تست‌ها

```bash
php vendor/bin/phpunit
```

CI روی هر پوش، مجموعهٔ تست را با MariaDB واقعی اجرا می‌کند
(پیکربندی در [`.github/workflows/ci.yml`](.github/workflows/ci.yml)).
تست‌های بار سنگین به‌صورت دستی و جداگانه اجرا می‌شوند — راهنما: [`tests/Load/README.md`](tests/Load/README.md)
و [`docs/scaling-guide.md`](docs/scaling-guide.md).
